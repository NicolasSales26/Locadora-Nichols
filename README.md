#  Locadora Nichols

Sistema de gestão de frota desenvolvido em Python.

Projeto prático do curso de Engenharia de Software - Estácio.

### ⚙️ Funcionalidades
- Controle de frota com status DISPONÍVEL/ALUGADO
- Cálculo automático de diárias
- Validação de regras de negócio
- Relatório de faturamento diário

### 💻 Tecnologias
- Python 3
- Estrutura de dados (dict)

### 🚀 Como rodar
python main.py
